# Specification compliance evaluation

**Review date:** 2026-10-08
**Scope:** Evidence-based comparison of the repository with the take-home specification, including required deliverables, illustrative payloads, and Appendix A. This is a static review of the checked-in snapshot; it does not infer the contents of an externally hosted walkthrough or production environment.

**Repository root for all evidence paths:** `/home/runner/work/Zapper.TeamLead.Assignment/Zapper.TeamLead.Assignment`.

## Executive finding

**The repository is not semantically complete against the specification.** It contains substantial architectural and infrastructure work, SQL objects, endpoints, and documentation, but the most important acceptance path—the exact Acme request/response contract and authenticated callback lifecycle—is not demonstrated and has direct contract mismatches. A successful build or the presence of similarly named handlers is not evidence that the Appendix A examples can be exchanged end to end.

### Most likely interview flags

1. **Acme integration does not match Appendix A.** The client sends the wrong route/authentication and materially different request fields, and cannot parse the documented successful response envelope. No Acme stub or contract-level payment test was found. This is a direct miss on a central required deliverable, not merely a design preference.
2. **Callbacks do not implement the specified trust, acknowledgement, and lifecycle semantics.** There is no Basic-auth or raw-body HMAC verification; successful callback actions return `201` rather than the required `200`; and handlers overwrite state without guarding against older events arriving later. This is also a direct spec miss.

**Close third:** an ambiguous Acme timeout is not durably recorded/reconciled before the request fails, and no Real Time Transaction Query (RTTQ) client is present. The code has a 30-second `HttpClient` timeout, but a timeout is not a recovery strategy.

These are evidence-based candidates only; the actual interview flags were not provided, so their identity cannot be known from this review.
